GridWorldEnv

env/gridworld.py

Description

Environnement de grille procédurale. À chaque reset(), une nouvelle grille 10×10 est générée aléatoirement avec des obstacles, une cible et une station de recharge. L'accessibilité est garantie par un algorithme BFS (_bfs_reachable).

Attributs

  • sizeTaille de la grille carrée. int = 10
  • max_energyÉnergie maximale de l'agent (décrémentée à chaque pas). int = 100
  • obstacle_densityFraction de la grille occupée par des murs. float = 0.15
  • agent_posPosition courante de l'agent [row, col]. list[int]
  • target_posPosition de la cible à atteindre. list[int]
  • station_posPosition de la station de recharge. list[int]
  • obstaclesListe des positions de murs. list[list[int]]

Méthodes

def reset(self) → Tensor(4, 10, 10)

Régénère une grille entière et retourne l'observation initiale (4 canaux : obstacles, cible, station, agent).

def step(self, action: int) → (obs, reward, done)

Exécute une action (0=Haut, 1=Bas, 2=Gauche, 3=Droite). Gère les collisions, l'énergie et les récompenses.

def get_local_observation(self) → Tensor(4, size, size)

Construit le tenseur d'observation à 4 canaux binaires.

def render(self) → np.ndarray(size, size)

Retourne un tableau 2D lisible (0=vide, 1=mur, 2=cible, 3=station, 4=agent).

Récompenses

Pas normal : -1.0 · Collision : -5.0 · Station : +10.0 · Cible : +100.0

Perception

modules/perception.py

Description

Encodeur CNN inspiré de ResNet. Compresse l'observation brute de la grille en un vecteur latent de 32 dimensions. L'espace latent est régularisé par SIGReg (pas de BatchNorm) pour empêcher le Latent Collapse.

Attributs

  • encoderPipeline CNN séquentiel complet. nn.Sequential

Architecture interne de encoder :

# Extraction de features Conv2d(4→32, 3×3, pad=1) → ReLU 2× ResidualBlock(32) # skip-connections Conv2d(32→64, 3×3, stride=2) # 10×10 → 5×5 2× ResidualBlock(64) # Projection latente Flatten → Linear(1600, 128) → ReLU Linear(128, 32)

Méthodes

def __init__(self, in_channels=4, latent_dim=32)

Construit l'encodeur. in_channels=4 correspond aux 4 canaux de la grille.

def forward(self, x) → s_t x: (B, 4, 10, 10) # observation brute s_t: (B, 32) # vecteur latent

Si x est 3D (pas de batch), unsqueeze(0) est ajouté automatiquement.

WorldModel

modules/world_model.py

Description

Simulateur interne de la physique du monde. Prédit l'état latent futur s_{t+1} à partir de l'état courant et d'une action, en utilisant un GRUCell comme mémoire temporelle et une prédiction résiduelle (s_next = s_t + δ).

Attributs

  • input_projProjette la concatenation (s_t, a_t) de dim 36 vers 128. Linear(36,128)+ReLU
  • rnn_cellCellule récurrente qui maintient la mémoire temporelle h_t. GRUCell(128, 128)
  • predictorPrédit le résidu δ à partir de l'état caché. Lin(128→128→128→32)
  • latent_dimDimension de l'espace latent. int = 32
  • hidden_dimDimension de l'état caché du GRU. int = 128

Méthodes

def init_hidden(self, batch_size, device) → h_0 h_0: (B, 128) # vecteur de zéros

Initialise l'état caché du RNN (mémoire vierge).

def forward_step(self, s_t, a_t, h_t) s_t: (B, 32) # état latent a_t: (B, 4) # action one-hot h_t: (B, 128) # état caché → (s_next, h_next)

Un pas de simulation. Utilisé pour l'inférence et la planification CEM.

def forward_seq(self, s_0, a_seq, h_0=None) s_0: (B, 32) # état initial a_seq: (B, T, 4) # séquence d'actions → (s_preds: (B,T,32), h_seq: (B,T,128))

Séquence complète en mode autorégressif (BPTT). Chaque prédiction est réinjectée comme entrée du pas suivant.

Actor

modules/actor.py

Description

Planificateur par Cross-Entropy Method (CEM). N'hérite pas de nn.Module — c'est un algorithme d'optimisation pur, sans paramètres apprenables. Il échantillonne N trajectoires, les simule dans le WorldModel, évalue le coût combiné et raffine la distribution sur M itérations.

Attributs

  • NNombre de trajectoires échantillonnées par itération. num_sequences
  • HProfondeur de simulation (nombre de pas imaginés). horizon
  • MNombre d'itérations de raffinement CEM. cem_iterations
  • KNombre de séquences "élites" retenues à chaque itération. elite_size
  • gammaFacteur d'actualisation pour le coût cumulatif. float = 0.9
  • action_dimNombre d'actions possibles (Haut/Bas/Gauche/Droite). int = 4

Méthodes

def plan(self, s_t, h_t, world_model, cost_module, s_goal, w_goal=1.0) → (action: int, sequence: Tensor, cost: float)

s_t : état latent actuel (1, 32).

h_t : état caché RNN actuel (1, 128).

world_model : instance de WorldModel pour simuler les trajectoires.

cost_module : instance de Cost pour évaluer les états.

s_goal : vecteur latent cible (1, 32).

w_goal : poids de la distance au goal dans le coût total.

Formule du Coût

# Boussole + Critique total_cost = w_goal × MSE(s_sim, s_goal) + cost_module(s_sim) # Lissage de Laplace pour les élites probs = (counts + 0.1) / (K + 0.1 × action_dim)

Cost

modules/cost.py

Description

Réseau Critique (Value Network). Estime le coût futur attendu d'un état latent. Entraîné par TD-Learning dans main_colab.py (1-step) et par N-Step TD dans train_critic_only.py. Le planificateur CEM minimise cette sortie.

Attributs

  • criticMLP simple : Linear(32→32) → ReLU → Linear(32→1). nn.Sequential

Méthodes

def __init__(self, latent_dim=32)

Construit le MLP du Critique.

def forward(self, s_t) → V(s_t): (B, 1) s_t: (B, 32) # état(s) latent(s)

Retourne un scalaire par état. Plus V est bas, meilleur est l'état pour le planificateur.

Équation d'entraînement (N-Step TD)

# Cible = somme de coûts sur N=3 pas target = -r_t + γ(-r_{t+1}) + γ²(-r_{t+2}) + γ³·V_target(s_{t+3}) # Signe inversé car le CEM minimise le coût

Configurator

modules/configurator.py

Description

Automate logique pur (n'hérite pas de nn.Module). Il agit comme le "cortex préfrontal" : il bascule l'objectif de l'agent entre la cible et la station de recharge en fonction de l'énergie restante.

Attributs

  • s_targetVecteur latent de la cible finale. Tensor (1, 32)
  • s_stationVecteur latent de la station de recharge. Tensor (1, 32)
  • latent_dimDimension de l'espace latent. int = 32

Méthodes

def set_goals(self, s_target, s_station)

Enregistre les vecteurs latents des deux objectifs (obtenus en passant des observations synthétiques dans la Perception).

def get_configuration(self, energy) → (s_goal, w_energy, w_collision, w_goal)

Si energy > 30 : s_goal=s_target, w_energy=0.1, w_goal=1.0

Si energy ≤ 30 : s_goal=s_station, w_energy=5.0, w_goal=2.0

w_collision est toujours fixé à 1.0.

ShortTermMemory

modules/memory.py

Description

Replay Buffer circulaire (l'"hippocampe" de l'agent). Stocke les transitions vécues sur CPU et permet de les rejouer lors de l'entraînement pour briser la corrélation temporelle.

Attributs

  • bufferListe circulaire stockant les transitions (x_t, a_t, x_next, r, done). list
  • capacityTaille maximale du buffer. Les anciennes transitions sont écrasées. int = 10000
  • positionCurseur d'écriture courant dans le buffer circulaire. int

Méthodes

def push(self, x_t, a_t, x_next, reward, done)

Stocke une transition. Les tenseurs sont convertis en CPU pour ne pas saturer la VRAM.

def sample_transitions(self, batch_size) → (x, a, x_next, r, d)

Échantillonnage aléatoire de transitions individuelles (TD classique 1-step).

def sample_sequences(self, batch_size, seq_len=8) → (x_0, a_seq, x_next_seq, r_seq, d_seq) # Vérifie : pas de done au milieu # Vérifie : pas de traversée du curseur

Extraction de séquences temporelles contiguës pour le BPTT (World Model) et le N-Step TD (Critique). Lève ValueError si pas assez de séquences valides.

SIGReg

modules/sigreg.py

Description

Sketch Isotropic Gaussian Regularizer. Fonction de perte qui force la distribution des vecteurs latents à rester proche d'une gaussienne isotrope N(0, I). Empêche le Latent Collapse sans heuristique EMA.

Attributs

  • num_projNombre de directions de projection aléatoires. int = 1024
  • tPoints d'évaluation de la fonction caractéristique. linspace(0, 3, 17)
  • phiFonction caractéristique gaussienne de référence. exp(-t²/2)
  • weightsCoefficients de quadrature trapézoïdale. Tensor(17)

Méthodes

def forward(self, proj) → loss: scalar proj: (B, D) ou (T, B, D)

Calcule la statistique d'Epps-Pulley : projette les vecteurs sur 1024 directions aléatoires, compare la fonction caractéristique empirique à celle d'une gaussienne standard, et retourne l'écart moyen à minimiser.
